{% if lang == 'en' %}What's in the toolkit{% else %}Architektura zestawu{% endif %}

{% if lang == 'en' %}The three routines in viewis-cad-tools.lsp work in any standard AutoCAD installation, with no external DLLs and no registry changes.{% else %}Trzy procedury zawarte w pliku viewis-cad-tools.lsp zostały przygotowane tak, by działać w każdym standardowym środowisku AutoCAD bez zewnętrznych bibliotek DLL i bez ingerencji w rejestr systemowy.{% endif %}

{% if lang == 'en' %}Download viewis-cad-tools.lsp{% else %}Pobierz viewis-cad-tools.lsp{% endif %}
{% if lang == 'en' %}Command: SELECTREVERSE{% else %}Polecenie: SELECTREVERSE{% endif %}

{% if lang == 'en' %}1. Invert selection{% else %}1. Odwrócenie zaznaczenia{% endif %}

{% if lang == 'en' %}AutoCAD has no simple built-in way to invert the current selection in Model space or in the active layout.{% else %}AutoCAD natywnie nie oferuje prostego odwrócenia aktywnego zbioru wskazań w obszarze Modelu lub bieżącego arkusza (Layout).{% endif %}

  • {% if lang == 'en' %}Reads the currently selected objects with (ssget "_I").{% else %}Pobiera aktualnie zaznaczone obiekty przez (ssget "_I").{% endif %}
  • {% if lang == 'en' %}Gathers every visible entity in the current space (DXF filter 410 = CTAB), skipping hidden objects (DXF code 60 = 1).{% else %}Zbiera wszystkie widoczne elementy z bieżącej przestrzeni (filtr DXF 410 = CTAB) ignorując obiekty ukryte (kod DXF 60 = 1).{% endif %}
  • {% if lang == 'en' %}Builds the difference set and selects it right away, grips included, with sssetfirst.{% else %}Tworzy nowy zbiór różnicowy i natychmiast go aktywuje wraz z uchwytami za pomocą sssetfirst.{% endif %}
{% if lang == 'en' %}Command: CALCULATEAREA{% else %}Polecenie: CALCULATEAREA{% endif %}

{% if lang == 'en' %}2. Totaling areas{% else %}2. Sumowanie powierzchni{% endif %}

{% if lang == 'en' %}The standard _AREA command makes you click points one by one, or add single outlines with the Add option.{% else %}Standardowe polecenie _AREA wymaga żmudnego klikania punktów lub pojedynczych konturów z opcją Add.{% endif %}

  • {% if lang == 'en' %}Filters objects of type *POLYLINE, CIRCLE, HATCH and REGION.{% else %}Filtruje obiekty typu *POLYLINE, CIRCLE, HATCH i REGION.{% endif %}
  • {% if lang == 'en' %}Reads each area through the ActiveX interface (vla-get-property Area), with error handling so damaged geometry doesn't break the run.{% else %}Odpytuje obiekty przez interfejs ActiveX (vla-get-property Area) z pełną izolacją błędów przed uszkodzoną geometrią.{% endif %}
  • {% if lang == 'en' %}Prints the total in m² along with the object count (the default conversion assumes the drawing is in centimeters).{% else %}Wyświetla gotową sumę w m² wraz z licznikiem obiektów (domyślny przelicznik dla rysunków w centymetrach).{% endif %}
{% if lang == 'en' %}Command: DWT{% else %}Polecenie: DWT{% endif %}

{% if lang == 'en' %}3. Instant DWT template{% else %}3. Natychmiastowy szablon DWT{% endif %}

{% if lang == 'en' %}Saving a template in CAD normally means clicking through the Save As dialog and picking a format.{% else %}Eksport szablonu w CADzie standardowo zmusza do przeklikiwania dialogów zapisu i wyboru formatu.{% endif %}

  • {% if lang == 'en' %}Saves the current drawing as VI.dwt in the folder set by the *path-acad* variable (or *path*).{% else %}Zapisuje bieżący stan rysunku jako VI.dwt do katalogu wskazanego zmienną *path-acad* (lub *path*).{% endif %}
  • {% if lang == 'en' %}Checks that the folder exists and creates any missing folders (vl-mkdir).{% else %}Automatycznie weryfikuje istnienie folderu i w razie potrzeby tworzy brakującą strukturę (vl-mkdir).{% endif %}
  • {% if lang == 'en' %}Turns off command echo (CMDECHO = 0) and overwrites the file without confirmation prompts (EXPERT = 2).{% else %}Wycisza komunikaty (CMDECHO = 0) i nadpisuje plik bez irytujących monitów (EXPERT = 2).{% endif %}
