1. Czym jest macroScript?

W 3ds Max zwykły plik .ms po wykonaniu znika z pamięci podręcznej interfejsu. Definicja macroScript rejestruje polecenie na stałe w systemie, dzięki czemu pojawia się ono w oknie Customize User Interface i można je przeciągnąć na pasek narzędzi lub przypisać do skrótu klawiszowego.

Pobierz viewis-regen-scripts.ms
INSTALACJA I SKRÓT

2. Jak dodać przycisk do paska?

Aby zarejestrować macroScript i mieć go pod ręką w interfejsie:

  1. Przeciągnij plik viewis-regen-scripts.ms bezpośrednio do okna rzutni (Viewport) lub uruchom przez Scripting → Run Script.
  2. Wejdź w menu Customize → Customize User Interface i przejdź do zakładki Toolbars.
  3. W rozwijanej liście Category wybierz kategorię ViewIs Tools.
  4. Przeciągnij pozycję Regen Scripts na dowolny pasek narzędzi na górnej belce programu.

3. Hot-Reload w praktyce

Zamiast restartować 3ds Maxa po każdej modyfikacji tworzonego narzędzia, procedura odświeża cały folder skryptów za pomocą funkcji fileIn w ułamku sekundy:

  • Izolacja wyjątków: Blok try ... catch przechwytuje błędy składniowe i wyświetla komunikat z getCurrentException() w oknie Listenera bez przerywania pętli.
  • Czarna lista: Tablica excludedFiles pozwala wykluczyć pliki tymczasowe lub ciężkie biblioteki pomocnicze.
  • Normalizacja ścieżki: Automatyczne sprawdzanie obecności folderu i korygowanie kończących ukośników zapobiega błędom IO.
