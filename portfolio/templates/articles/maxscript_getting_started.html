{% if lang == 'en' %}1. What is a macroScript?{% else %}1. Czym jest macroScript?{% endif %}

{% if lang == 'en' %}In 3ds Max, a regular .ms file is gone from the interface once it has run. A macroScript definition registers the command permanently, so it appears in the Customize User Interface window and can be dragged onto a toolbar or assigned a keyboard shortcut.{% else %}W 3ds Max zwykły plik .ms po wykonaniu znika z pamięci podręcznej interfejsu. Definicja macroScript rejestruje polecenie na stałe w systemie, dzięki czemu pojawia się ono w oknie Customize User Interface i można je przeciągnąć na pasek narzędzi lub przypisać do skrótu klawiszowego.{% endif %}
