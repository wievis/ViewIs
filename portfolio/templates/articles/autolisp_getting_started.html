{% if lang == 'en' %}1. Loading your first .lsp file{% else %}1. Pierwsze wczytanie pliku .lsp{% endif %}

{% if lang == 'en' %}An AutoLISP file is a plain text file with the .lsp extension. To try it out once in an open drawing:{% else %}Plik AutoLISP to czysty plik tekstowy z rozszerzeniem .lsp. Aby go jednorazowo wypróbować w otwartym rysunku:{% endif %}

{% if lang == 'en' %}Method A (Drag and drop){% else %}Metoda A (Przeciągnij i upuść){% endif %}

{% if lang == 'en' %}Drag the .lsp file from Windows Explorer straight into the drawing area (Model space).{% else %}Upuść plik .lsp z Eksploratora Windows prosto na czarny obszar kreślenia (Model).{% endif %}

{% if lang == 'en' %}Method B (APPLOAD command){% else %}Metoda B (Polecenie APPLOAD){% endif %}

{% if lang == 'en' %}Run the APPLOAD command, select the downloaded file and click Load.{% else %}Wpisz polecenie APPLOAD, wskaż pobrany plik i zatwierdź przyciskiem Load.{% endif %}

{% if lang == 'en' %}2. Configuring Trusted Paths{% else %}2. Konfiguracja Trusted Paths{% endif %}

{% if lang == 'en' %}By default, AutoCAD blocks scripts from untrusted folders and shows a Security Concern warning. To stop the prompts:{% else %}AutoCAD domyślnie blokuje skrypty z nieautoryzowanych folderów, wyświetlając ostrzeżenie Security Concern. Aby wyeliminować monity:{% endif %}

  1. {% if lang == 'en' %}Run the OPTIONS command (shortcut OP) and open the Files tab.{% else %}Wpisz polecenie OPTIONS (skrót OP) i przejdź do zakładki Files.{% endif %}
  2. {% if lang == 'en' %}Expand the Trusted Locations section.{% else %}Rozwiń sekcję Trusted Locations (Zaufane lokalizacje).{% endif %}
  3. {% if lang == 'en' %}Click Add..., then Browse... and select your scripts folder.{% else %}Kliknij Add..., a następnie Browse... i wskaż swój folder na skrypty.{% endif %}
  4. {% if lang == 'en' %}Important: Add three dots at the end of the path (...), e.g. C:\...\lsp\..., so AutoCAD also trusts all subfolders.{% else %}Ważne: Dodaj na końcu ścieżki trzy kropki (...), np. C:\...\lsp\..., aby AutoCAD uznał za zaufane również wszystkie podkatalogi.{% endif %}
  5. {% if lang == 'en' %}Click Apply and OK.{% else %}Kliknij Apply i OK.{% endif %}
{% if lang == 'en' %}Command: REGENLISP{% else %}Polecenie: REGENLISP{% endif %}

{% if lang == 'en' %}3. Reloading scripts on the fly{% else %}3. Przeładowywanie skryptów w locie{% endif %}

{% if lang == 'en' %}Instead of restarting AutoCAD after every code edit, the REGENLISP routine recursively reloads all files in a fraction of a second:{% else %}Zamiast restartować AutoCADa po każdej edycji kodu, procedura REGENLISP rekurencyjnie odświeża wszystkie pliki w ułamku sekundy:{% endif %}

{% if lang == 'en' %}Set your own path in the code{% else %}Wskaż swoją ścieżkę w kodzie{% endif %}

{% if lang == 'en' %}In the line (setq *path-acad* "...") replace UZYTKOWNIK with your Windows profile name, or give the exact path to the folder. Remember to use forward slashes /.{% else %}W linijce (setq *path-acad* "...") zamień UZYTKOWNIK na nazwę swojego profilu lub podaj dokładną ścieżkę. Pamiętaj o ukośnikach / zamiast \.{% endif %}

  • {% if lang == 'en' %}Excluded folders: The ignore list skips temporary folders (.git, .venv, archiwum, test).{% else %}Folder isolation: Lista ignore pomija foldery tymczasowe (.git, .venv, archiwum, test).{% endif %}
  • {% if lang == 'en' %}Fault tolerance: Uses vl-catch-all-apply, so an error in one script does not stop the others from loading.{% else %}Odporność na awarie: Wykorzystuje vl-catch-all-apply – błąd w jednym skrypcie nie przerywa ładowania pozostałych.{% endif %}
